Pixel charms

The white plate is gone. Each charm is drawn straight onto the band, so every pixel that is not the band or the charm is fully transparent — alpha 0, not white. Shipped as PNG (6× nearest-neighbour, 720×180) and as SVG rects, so it stays crisp at any density.

How it is made

TransparencyWritten as RGBA PNG with alpha 0 outside the band and charm. No white fill, no matte.
CrispnessEvery pixel is duplicated 6× nearest-neighbour, so the blocks stay square; in the app the SVG is used at any dp.
SourceASCII grids in generate.py — one letter per colour. Edit a grid, re-run, both files rebuild.
Charmbow, star and heart share one band, so switching charm never changes the banner's height.
