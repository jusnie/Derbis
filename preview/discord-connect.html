Why it never opened Discord

The hand-off checked resolveActivity() before launching, and since Android 11 that returns null for any package the app cannot see — Discord is not in the manifest's <queries>. Every Discord candidate was skipped and the code fell through to a browser tab, then left the panel in SigningIn.

What changed

Launch first, catch ActivityNotFoundException, try the next candidate. A <queries> block now names the three Discord packages and the discord:// scheme, so the panel can tell you whether the app exists at all instead of promising a hand-off that cannot happen.

Callback, unchanged

Discord returns to discord-<app id>:/authorize/callback, which Derbis claims in its manifest. That URI has to be registered on the Discord application as well — an unregistered redirect shows an error inside Discord and never comes back.
