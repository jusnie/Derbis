Pixel — decks & motion

The animated surfaces, re-skinned: the cover-flow deck, the vinyl deck, word-by-word lyrics, the fullscreen lyric page and the transitions between screens. Everything is CSS and inline SVG — no frames, no GIFs, no bundled art. The motion switch below is the same switch the app reads: it is LocalAnimationsEnabled, which is off when the user turns animations off or the system asks for reduced motion. Nothing here animates if that flag is false.

Toggle it — this is LocalAnimationsEnabled, not a preview-only switch.
