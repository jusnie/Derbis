Default vs Pixel

The standing rule is that Pixel applies only while it is equipped. So this page is not a before-and-after: it is the same screen markup rendered through two palettes, and the default on the left is exactly what the app still does when Pixel is not equipped. Nothing in the right column is a rebuild of the screen — it is the same rows, the same deck, the same order.

Same DOM node, variables swapped — the test for whether a screen is truly skinnable.
