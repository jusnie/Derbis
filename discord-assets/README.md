# Derbis Discord Rich Presence assets

All assets use the Derbis black-and-white identity. Upload each file in
**Discord Developer Portal → Derbis → Rich Presence → Art Assets** and give it the exact,
case-sensitive key below.

| Asset key | File | Intended presence state |
| --- | --- | --- |
| `derbis_invite` | `derbis_invite.png` | 1920×1080 black-and-white listening / invite background. |
| `derbis_listening` | `derbis_listening.png` | Default listening large image. |
| `derbis_jam` | `derbis_jam.png` | Derbis Jam shared-listening large image. |

Uploading an asset makes its key available to Discord; Derbis must reference that key in a Rich Presence payload for it to appear.
