# Derbis 1.8.0

**Pixel skin, a 3D queue stage for Vinyl, home servers in unified search, and buttery-smooth
Spotify Canvas.** Derbis 1.8.0 introduces the pink hard-edged Pixel skin across every screen and
exported card, rebuilds the Vinyl deck around the live queue, brings Subsonic and Navidrome
libraries into the same search and player as streamed music, adds mono output, artwork ceilings,
status-bar lyrics and explicit filtering, and overhauls Spotify Canvas resolution and loop caching
so animated covers load reliably and play without dropping display refresh rates.

## What's New

### Pixel skin

- **Pixel** replaces Nocturne 78: blush paper ground, plum ink, hard 0 dp rectangular geometry on
  every card, sheet, button, dialog, cover and mini player, and monospace headings/labels with
  high-contrast rose accents across every surface — including Playback Diagnostics, modal sheets
  and exported share cards.
- Selecting **Settings → Appearance → Skin → Pixel** switches the whole app at once, and any
  install that previously saved Nocturne 78 lands automatically on Pixel.

### Vinyl queue stage

- **Vinyl** turns the queue into a 3D cover-flow stage: the active track sits flat and forward in
  the centre while neighbouring queue tracks angle away on the Y axis with their own cover art.
- Advancing or stepping back rotates the row on a single shared animation progress so cards never
  drift apart, and snaps in a single frame when animations are turned off.

### Home server & discovery

- **Subsonic and Navidrome** (**Settings → Integrations → Home server**): connect your own server,
  verify credentials before saving, and play your personal FLAC/ALAC/MP3 library alongside
  streamed results in one unified search.
- **Typo-tolerant search** widens matching when exact and prefix passes come back thin, without
  perturbing normal search ranking.
- **Explicit content filter** offers three modes — show all, hide explicit, or explicit only —
  using provider flags rather than title guesswork.
- **More like this** and **Less like this** in the track action sheet persist across restarts and
  steer recommendations for both the track and its artist.

### Audio, lyrics & bandwidth controls

- **Mono output** folds stereo to mono in real time for single-earbud listening, mono speakers, or
  one-sided hearing loss, saved with audio settings and backups.
- **Artwork quality ceiling** (**Settings → Interface → Artwork quality**) caps requested and
  cached cover dimensions at 480, 720 (default) or 1080 px across CDNs.
- **Status bar lyrics** post the active synced lyric line into a silent notification so you can
  read along from the shade.
- **Spotify Canvas**: multi-tier `.mp4` resolution (Pathfinder GraphQL, regional `spclient`
  `canvaz-cache` protobuf with `client-token`, and verified fallback mirrors), canonical
  YouTube-to-Spotify track matching, disk caching + next-track pre-warming via Media3
  `SimpleCache`, a 20-second retained RAM back-buffer for zero-gap loop wraparound, and
  `VIDEO_CHANGE_FRAME_RATE_STRATEGY_OFF` so 90/120 Hz LTPO displays never throttle down during
  Canvas playback.

## What's Fixed

- **Spotify Canvas sign-in** stays on `accounts.spotify.com` with a compatible Chrome user agent,
  intercepts the post-login redirect before the DRM web player loads blank, reads `sp_dc` cleanly
  and immediately invalidates cached negative lookups when an account connects.
- **Playback resilience**: fixed cellular `STATE_IDLE` stalls after stream resolution, corrected
  `REEL_AUDIO` probe classification and circuit health, recovered stalled PCM16 audio sinks, and
  fixed `MonoAudioProcessor` dropping output buffers.
- **Discord Rich Presence** now publishes both start and end timestamps plus the active synced
  lyric line on the Social SDK path while sharing a unified 4-second presence rate budget.
- **Wrapped story & receipt export**: fixed header button spacing in Wrapped stories and added
  720 px / 540 px bitmap fallbacks when exporting receipt cards on memory-constrained devices.
- **Now Playing audio badge**: the codec/tier pill (`AAC · Low`, `FLAC · Lossless`, `Dolby Atmos`)
  now wraps tightly to the exact label width instead of stretching to a fixed wide box.
