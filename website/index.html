GOOGLE AUTHORIZATION

Connection needs one public setting

Set a Google OAuth Web application Client ID in website/config.js, enable YouTube Data API v3, and add this site’s HTTPS origin to Google Cloud’s authorized JavaScript origins.

The client ID is public. Never add a Google client secret, browser cookies, or a YouTube Music account session to this site.
